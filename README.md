# Nature Paisagismo - site institucional

Site one-page da **Nature Paisagismo**, centro de jardinagem e loja de viveiro em Porto Alegre - RS.

## Estrutura

```
index.html   # página única (hero, sobre, projeto antes/durante/depois, serviços, depoimentos, mapa, FAQ)
styles.css   # estilos (tema claro, verde-floresta)
script.js    # número do WhatsApp, menu mobile, animações, carrossel, FAQ
assets/      # fotos da empresa (obra-*.jpg), fotos de apoio e favicon
```

Sem build: HTML, CSS e JS puros.
