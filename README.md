# Nature Paisagismo - site institucional

Site one-page da **Nature Paisagismo**: projetos paisagísticos, jardim vertical, design de pedras, reforma e manutenção de jardins em Porto Alegre - RS. Atua desde 2008.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, projeto antes/durante/depois, galeria, depoimentos, contato, mapa, FAQ)
styles.css   # estilos (tema claro, verde-floresta; header e hero escuros no estilo do site da Elegance Pisos)
script.js    # número do WhatsApp, menu mobile, header ao rolar, animações, carrossel, galeria, FAQ
assets/      # logo, favicon, fotos e vídeos da empresa
```

Sem build: HTML, CSS e JS puros.
